# RAIV_Fish Bot — заказы (Make)

Telegram-бот заказов RAIV FISH: каталог, корзина, доставка, база клиентов, бонусы, промокоды, рассылки, отчёты, AI-помощник владельца.

- Рабочий сценарий Make: 7707233 «Заказы v5 — РАБОЧИЙ» (вебхук 3818482).
- Все объекты, ID и откат: `backup/RESTORE.md`.
- Адреса вебхуков в репозиторий не записываем: репозиторий публичный.

## ⚠️ Генератор отстаёт от рабочего бота
`generate_blueprint.py` собирает **v4**. Рабочий бот уже **v5**: короткий старт, слоты, номер заказа, статусы, оценка, рефералка.
Пока логика v5 не перенесена в генератор, **не загружайте `bp.json` в сценарий 7707233**, иначе бот откатится на v4.

## Как изменить цены / наличие (после переноса v5 в генератор)
Отредактируйте список `cats` в `generate_blueprint.py` (третье значение: 1 — в наличии, 0 — нет ❌),
запустите `python3 generate_blueprint.py` и загрузите `bp.json` в сценарий.
