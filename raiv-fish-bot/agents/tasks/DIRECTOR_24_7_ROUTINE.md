# Рутина «🧭 Директор 24/7» — создать в claude.ai → Routines

Почему вручную: рутины, созданные инструментом из сессии, не получают коннектор Make и репозиторий (ответ сервера:
«ask the user to create it from the claude.ai routines UI»).

Настройки:
- Название: 🧭 Директор 24/7
- Расписание: каждые 3 часа, часовой пояс Europe/Berlin, минута 07 (cron `7 */3 * * *`)
- Репозиторий: billibons13/Billibons
- Коннекторы: Make
- Режим: новая сессия при каждом запуске
- Промт: полный текст — у выключенной рутины trig_01UXZcrkHV62rLoCHGkwhJmV («🧭 Директор 24/7 (с Make)»);
  его можно открыть в списке Routines и скопировать, либо попросить Claude прислать его в чат.

После создания: сообщить в чат — директор проверит первый запуск и выключит дубликаты.
