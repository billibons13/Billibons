# Ежедневные планы и отчёты команды RAIV FISH

Распоряжение директора от 03.10.2026 (по поручению владельца): каждый сотрудник каждый рабочий день
составляет **план на день** утром и сдаёт **отчёт о проделанной работе** вечером.

## Файл дня
Один файл на день: `agents/daily/ГГГГ-ММ-ДД.md`. В нём по разделу на каждого сотрудника.
Утром сотрудник заполняет «План», вечером — «Сделано», «Не сделано и почему», «Нужно от владельца».

## Шаблон раздела сотрудника
```
## <эмодзи> <должность>
**План (до 09:00)**
1. … — результат, по которому видно, что сделано
2. …
**Отчёт (до 20:00)**
- ✅ Сделано: … (ссылка на файл, коммит, выполнение Make)
- ⏳ Не сделано и почему: …
- ❓ Нужно от владельца: … (решение «да/нет», текст на одобрение)
```

## Правила
- 1–3 пункта плана, каждый проверяемый: «подготовить 3 черновика постов», а не «работать над каналом».
- В отчёте только факты: что изменилось, где это лежит. Если дел нет — «без изменений, проверил: …».
- План и отчёт не дают права обходить правила `DIRECTOR.md`: цены, скидки, удаление данных,
  выкат в 7707233 и публикации — только после «да» владельца.
- Данные клиентов (телефоны, адреса) в файлы дня не попадают — только количество и номера заказов.

## Сводка директора
Вечером директор читает отчёты и отправляет владельцу одно сообщение (не больше 1 000 знаков):
«🧭 Итог дня ГГГГ-ММ-ДД» — что сделано по сотрудникам одной строкой, что сорвалось, что нужно решить.
Пятничная сводка заменяется недельным отчётом директора (понедельник 08:52).
