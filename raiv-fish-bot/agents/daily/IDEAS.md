# Ежедневные идеи: 3 улучшения бота от каждого сотрудника

Распоряжение владельца от 03.10.2026: **каждый из 10 сотрудников каждый день предлагает 3 варианта
улучшения бота по своей части**. Директор собирает 30 идей, убирает повторы и уже сделанное,
структурирует и отправляет владельцу в Telegram для просмотра (ежедневно 19:47, Europe/Berlin).

## Кто и о чём
| Сотрудник | Его часть бота |
|---|---|
| 🛡 Инженер надёжности | ошибки, скорость ответа, вебхук, оплаты, резервные копии |
| 🔎 Аудитор UX | путь клиента от /start до заказа, тексты кнопок, эталон 10/10, новинки Telegram |
| 📊 Аналитик продаж | воронка, брошенные корзины, средний чек, отчёты владельцу |
| 📣 Контент-менеджер | связка канал/TikTok/Instagram/Facebook ↔ бот, тексты, фото |
| 💌 CRM-маркетолог | повторные заказы, бонусы, напоминания, рефералка |
| 🗂 Менеджер каталога | товары, названия, фото, разделы, переводы |
| 📦 Агент склада | наличие, сводка склада, кнопки владельца |
| ✅ Контролёр готовности | что мешает продавать бот другим магазинам, чек-лист |
| 🧪 Тестировщик релизов | слабые места, найденные тестами, защита от ошибок ввода |
| 💼 Менеджер продаж бота | что добавить, чтобы бот легче продавался (функции, демо, языки) |

## Формат одной идеи
`Что сделать — зачем (польза для заказов/владельца) — сложность S/M/L`
- Идея опирается на факты: выполнения Make, data stores, код генератора, отзывы, новинки Bot API.
- Не повторять идеи прошлых 7 дней (`daily/ideas/*.md`) и уже сделанное (`director_log.md`, `backup/RESTORE.md`).
- Идеи о ценах, скидках, бесплатных тарифах и удалении данных — только как вопрос владельцу.

## Что делает директор
1. Пишет все 30 идей в `daily/ideas/ГГГГ-ММ-ДД.md` (по сотрудникам), коммит и пуш.
2. Структурирует для владельца: группы «🔥 Сделать сейчас (топ-5)», «⚙️ Улучшения бота», «📈 Продажи и маркетинг»,
   «🛡 Надёжность», каждая идея — одна строка с номером и автором-эмодзи; повторы объединяет.
3. Отправляет в Telegram (инструмент Make 7706891, sendMessage, chat_id 6883357001), каждое сообщение до 3 800 знаков,
   при необходимости 2–3 сообщения. В конце: «Ответьте номерами идей в чате Claude — что делать».
4. Ничего из идей не внедряет сам: в рабочий сценарий 7707233 — только после «да» владельца.
