# Разведка новинок Telegram для RAIV FISH — 01.10.2026

Собрал 🔎 Аудитор UX и разведчик новинок по заданию директора. Актуальная версия Bot API — 10.3 (24.08.2026).
Официальные сайты Telegram были закрыты прокси сессии: данные из поисковой выдачи и changelog'ов библиотек
(github.com/apimorphism/telegramium/releases, github.com/tg-rs/tgbot). Перед внедрением сверять с core.telegram.org/bots/api-changelog.
Модуль Make «Telegram → Make an API Call» (telegram:UniversalAPICall) в аккаунте есть — новые методы доступны.

Важно: **Stars нельзя использовать для физических товаров** — для рыбы только Telegram Payments через провайдера (Stripe) или внешняя ссылка.

## C. Топ-5 на 2 недели (предложение директора)
1. Политика данных (BotFather + страница на Netlify).
2. Цветные кнопки в боте и под постами.
3. Кнопки «Заказать» / «Витрина» под постами канала (бот публикует посты от имени канала).
4. Личные сообщения канала, обрабатываемые ботом.
5. Mini App: полный экран, ярлык на домашний экран, «поделиться товаром с другом».
Следующая волна (нужно решение владельца): нативная оплата Stripe в Telegram, Telegram Business, реклама через предложенные посты.
