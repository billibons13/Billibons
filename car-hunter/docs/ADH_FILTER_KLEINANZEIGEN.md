# ADH: фильтр «TÜV 2028+, до 1000 €, коробка / мотор / без ржавчины» + источник Kleinanzeigen

Задача T-20261009-0037 · 09.10.2026 · исполнитель 🛠 Make-инженер · система Auto Deal Hunter (папка Make 402182).

Поручение владельца (09.10): «Настраивай так, чтобы все новые авто, которые я выставлял по фильтру
TÜV 28, до 1000 €, коробка работала нормально, мотор работал нормально, без ржавчины, выкладывались
в Kleinanzeige».

Как понято (подтверждено владельцем через директора): **новые** объявления Kleinanzeigen, подходящие под
критерии, приходят карточкой в Telegram-бот «Auto Deal Hunter Bot». Автопубликации на Kleinanzeigen нет и
не будет: у площадки нет публичного API, а скрейпинг и автоматизация входа нарушают её условия.

---

## 1. Как работает цепочка

```
Kleinanzeigen «Suche speichern» (e-mail-уведомления, делает владелец)
  → Gmail: фильтр по отправителю → пересылка на почтовый хук ADH-01
  → ADH-01 Scout 7852688: письмо → текст → AI-разбор (Claude Haiku) → строки в БД (Cloudflare D1, таблица cars)
  → для каждого НОВОГО объявления — вызов ADH-02
  → ADH-02 Pipeline 7852690:
       1) жёсткий фильтр без AI: цена ≤ budget_max, стоп-слова (SQL по настройкам)
       2) HU/TÜV без AI: год из текста (регулярные выражения) → если известен и < hu_min_year — отсев
       3) AI-инспектор (Claude Sonnet): КПП / мотор / ржавчина по тексту продавца + риск + рыночная цена
       4) карточка в Telegram
  → ADH-03 Manager 7852709: кнопки под карточкой (⭐ ❌ 🔍 ✍️ 🔗 🤖 ➡️)
```

Настройки фильтра лежат в БД D1, таблица `settings` (её видно в боте: «⚙️ Фильтры»; менять: `/set ключ значение`).

## 2. Логика фильтра

### 2.1 Жёсткие фильтры (детерминированно, без AI)

| Критерий | Где | Значение | Что происходит |
|---|---|---|---|
| Цена | `settings.budget_max` | `1000` | цена > 1000 € → `filtered_out`, «дороже бюджета». Цена не указана — не отсеивается. |
| Стоп-слова | `settings.stopwords` (владельца, не менял) | `Motorschaden, Getriebeschaden, defekt, Export, Bastler, ohne TÜV, Unfallwagen, Totalschaden` | слово в заголовке/описании → отсев до AI (экономит кредиты). |
| HU/TÜV | `settings.hu_min_year` | `2028` | год HU из текста < 2028 → `filtered_out`, причина «HU/TÜV: 2026 …». |

Разбор HU/TÜV (ADH-02, модули 11–12, проверено на 17 примерах):

- `HU bis 05/2028`, `TÜV 2028`, `TÜV 3/28`, `HU 11/27`, `TÜV bis 03.2026`, `tuv 27` → год (2028, 2028, 2028, 2027, 2026, 2027);
- `TÜV neu`, `HU/AU neu`, `frischer TÜV`, `HU 2 Jahre` → «новый» = текущий год + 2 (сейчас 2028);
- `ohne TÜV`, `kein TÜV`, `TÜV abgelaufen` → «нет» (год 0) → отсев;
- `Neuer TÜV nötig/fällig` → не считается новым;
- **HU не указана → не отсеивается**, в карточке: «📋 HU/TÜV: ? — не указано, уточнить у продавца».

### 2.2 Мягкие критерии (AI-инспектор, только по тексту продавца)

Для КПП, мотора и ржавчины AI ставит одно из трёх:

- «ок по словам продавца» — продавец прямо пишет, что исправно / ржавчины нет;
- «дефект: <цитата>» — дефект назван прямо;
- «не указано — проверить при осмотре» — текст молчит.

Отсев (`reject`) — **только** при явно названном дефекте: Getriebe defekt / Getriebeschaden / Gang springt raus;
Motorschaden / Motor defekt / springt nicht an / läuft nicht / Zylinderkopfdichtung defekt; Rost / rostig /
Durchrostung / Rostlöcher; Bastlerfahrzeug / für Export / nicht fahrbereit. Отрицания («kein Rost», «rostfrei»,
«kein Motorschaden») дефектом не считаются. При сомнении — не отсеивать. Отсеянные AI-ом получают
`filtered_out` и причину «дефект по тексту: …».

AI никогда не утверждает, что машина исправна: в карточке всегда «по словам продавца» и строка
«ℹ️ Состояние — только по тексту продавца, не проверено. Нужны осмотр и пробная поездка.»

### 2.3 Какие карточки приходят

`settings.send_all_matches = 1` — приходят **все** объявления, прошедшие фильтры, даже если Deal Score ниже
порога `score_threshold` (70). Так выполняется «все новые авто по фильтру». Вернуть «только выгодные»:
`/set send_all_matches 0`.

### 3.1 «✍️ Написать продавцу» — черновик, отправляешь сам

У Kleinanzeigen нет API для сообщений, поэтому **бот продавцам ничего не отправляет — никогда**.
Кнопка «✍️ Написать продавцу» (ADH-03, модули 261–263) без AI, по шаблону, присылает:

- вежливый текст на немецком в моноширинном блоке (нажми — скопируется):
  > Hallo, ich interessiere mich für Ihr Fahrzeug „<заголовок>“. Ist es noch zu haben? Vorab ein paar kurze
  > Fragen: 1. Bis wann ist die HU/TÜV gültig? 2. Schaltet das Getriebe sauber …? 3. Läuft der Motor
  > einwandfrei …? 4. Gibt es Rost …? 5. Wann wäre eine Besichtigung mit Probefahrt möglich? 6. Ist beim Preis
  > noch etwas Spielraum? Vielen Dank und viele Grüße
- строку перевода на русский;
- кнопку «🔗 Открыть объявление» → открываешь, жмёшь «Nachricht schreiben», вставляешь, отправляешь сам;
- кнопку «🤖 AI-вариант» — персональный черновик через Claude Haiku (1 AI-вызов, тратит кредиты; нажимать по желанию).

Старые карточки (до 09.10) с кнопкой «✉️ Письмо продавцу» теперь тоже получают шаблон без AI.

## 4. Что сделать владельцу (≈ 10 минут)

**Шаг 1. Сохранённый поиск на Kleinanzeigen.**
kleinanzeigen.de → Auto, Rad & Boot → Autos → фильтры: **Preis bis 1000**, Ort + Umkreis (как удобно),
по желанию Erstzulassung / Kilometerstand → кнопка **«Suche speichern»** → включить
**E-Mail-Benachrichtigung** (сразу / ежедневно). Можно несколько поисков (разные регионы).
Совет: в поле поиска можно добавить «TÜV» — тогда больше объявлений с указанной HU.

**Шаг 2. Адрес почтового хука ADH-01.** Make → Webhooks → хук **«ADH Scout — письма с объявлениями»** →
скопировать адрес вида `…@hook.eu1.make.com` (в этот документ адрес намеренно не записан).

**Шаг 3. Пересылка в Gmail.** Gmail → ⚙️ → Все настройки → «Пересылка и POP/IMAP» → «Добавить адрес
пересылки» → вставить адрес из шага 2. Gmail отправит письмо с кодом на этот адрес — ADH-01 сам перешлёт
его тебе в Telegram («📩 Служебное письмо на адрес Scout …»). Ввести код в Gmail → подтвердить.

**Шаг 4. Фильтр Gmail** (только письма сохранённого поиска, а не переписка по твоим объявлениям):
- От: `noreply@kleinanzeigen.de`
- Не содержит в теме (в поле «Не содержит слов» или запросом):
  `-subject:("Deine Anzeige" OR "Deine Anfrage" OR "Nutzer-Anfrage")`
- Действие: «Переслать на» → адрес хука. Галочку «Применить к совпадающим цепочкам» **не** ставить
  (иначе уйдут старые письма и потратят кредиты).
- [ПРЕДПОЛОЖЕНИЕ] Точная тема писем сохранённого поиска пока неизвестна (в почте их ещё нет). Лучше дождаться
  первого письма и сделать фильтр по его теме («Фильтровать похожие»). ADH-01 дополнительно сам пропускает
  письма с темами «Deine Anzeige», «Deine Anfrage», «Nutzer-Anfrage», «Passwort», «Rechnung».

**Шаг 5.** Переслать директору / в этот чат **1–2 настоящих письма** сохранённого поиска — по ним доведём
разбор (сейчас он сделан «терпимым» без образца, помечен [ПРЕДПОЛОЖЕНИЕ]).

## 5. Ограничения

- **Состояние — только по тексту продавца.** Письмо-уведомление Kleinanzeigen обычно содержит только заголовок,
  цену, место и, возможно, начало описания. Полный текст объявления мы не скачиваем (скрейпинг запрещён),
  поэтому многие карточки будут «не указано — проверить при осмотре». Обязательно: осмотр, пробная поездка,
  проверка снизу на подъёмнике / с фонарём, OBD-сканер.
- Дефект, о котором продавец промолчал, система не видит. «Ок по словам продавца» ≠ «исправно».
- Цена «VB» без числа → цена неизвестна → не отсеивается по цене.
- Стоп-слово `defekt` (настройка владельца) отсеивает и мелочи («Radio defekt»), а `Motorschaden` — и фразу
  «kein Motorschaden». Если хочешь мягче: `/set stopwords Getriebeschaden,Getriebe defekt,Motor defekt,Export,Bastlerfahrzeug,ohne TÜV,Totalschaden`
  — остальное решит AI-инспектор (без отсева при отрицаниях).
- Кредиты Make: на одно письмо ≈ 1 AI-вызов разбора + по 1 AI-вызову на каждое объявление, прошедшее цену,
  стоп-слова и HU. Ограничить поток — сузить радиус / регион в сохранённом поиске.

## 9. Открытые вопросы

1. Нужны 1–2 настоящих письма сохранённого поиска Kleinanzeigen, чтобы подтвердить разбор и тему для фильтра Gmail.
2. Если «выкладывались в Kleinanzeige» означало **публикацию своих объявлений** — автоматизировать нельзя
   (нет API, против условий площадки); можно сделать черновики текста объявлений в боте — по отдельному поручению.

   `/set send_all_matches 0`.
