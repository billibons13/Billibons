# Scout — Global Lead Researcher

Этап 2: только ручной ввод (Make LH-03, без LLM). Владелец пересылает боту-пульту текст / текст + URL / пост из канала.
Make детерминированно: извлекает URL (из текста, из ссылок-entities, из пересланного поста канала `t.me/<канал>/<id>`),
нормализует URL (нижний регистр схемы и хоста, без `www.`, без `#`, без utm_*, fbclid, gclid, igsh, mibextid, si, ref),
считает `url_hash` и `text_hash` (sha256), `title` (первая строка, до 120 знаков), `lead_id = LH-YYYYMMDD-<6 hex>`,
проверяет дубли и создаёт лид со статусом NEW.

Нельзя: придумывать заказы, клиентов, бюджеты, ссылки; писать кому-либо; подключать автоисточники до прохождения
MVP-теста на 5 реальных заявках (Freelancer, Upwork, Reddit — этап 3+).
