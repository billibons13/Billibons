# Lead Hunter — тесты этапа 2

## Автотесты без Make
`python3 scripts/scoring.py` — формула, caps, grade, проверка JSON (в т.ч. «битый» JSON, scores вне 0–10, нет поля).

## Тесты в Telegram (данные — tests/TEST_DATA.md, помечены [TEST])
| Тест | Действие | Ожидаем |
|---|---|---|
| valid lead | T1 | карточка, grade по баллу, причины 10 оценок, кнопки ✅ ❌ 🔍 |
| no budget | T2 | budget = null, оценка бюджета 3 «не опубликован» |
| no URL | T3 | лид создан, source_url = null, score ≤ 59, причина в карточке |
| budget < 500 € | T4 | score ≤ 59, причина «бюджет < 500 €» |
| suspicious | T5 | risk_flags не пуст, score ≤ 39, REJECT |
| duplicate | T6 | «♻️ Дубликат LH-…», новый лид не создан, событие DUPLICATE_DETECTED |
| malformed JSON | подмена ответа Analyst | до 3 попыток, затем ERROR + сообщение владельцу |
| чужой chat_id | сообщение с другого аккаунта | «Access denied», лид не создан, событие SECURITY_DENIED |
| кнопки | ✅ / ❌ + причина / 🔍 | статус и запись в lh_decisions, ответ бота |
| /pause → заявка → /resume | | во время паузы лид NEW без AI; после /resume — карточка |
| расходы | после 5 заявок | 5 записей в lh_runs с токенами и стоимостью, /today показывает сумму |
