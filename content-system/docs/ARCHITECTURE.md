нет дешёвой альтернативы (публикация IG, метрики IG). AI в Make — только через **свой ключ Anthropic (BYOK)**
модулем Anthropic Claude → «Create a Prompt» со своим подключением; модуль «Simple Text Prompt» работает «без подключения»
и тратит AI-кредиты Make — **не использовать** [ПРОВЕРЕНО: Make API, описание модуля].
Кредиты: 1 модуль ≈ 1 кредит; оценки ниже — [ПРЕДПОЛОЖЕНИЕ], сверить первым прогоном.

| ID | Название | Триггер | Модули | Кредитов за запуск | В месяц (12 роликов) | Где лучше |

## 7. Content Director — логика AI-агента

Новая карточка `agents/team/CONTENT_DIRECTOR.md` (после «да»): подчиняется директору, работает в паре с действующим
📣 контент-менеджером (тот ведёт канал; Content Director — короткие видео и воронку). Запуск — рутина Claude, вс 18:07.

### Недельный цикл
| День | Действие |
|---|---|
| Вс вечер | читает метрики недели, каталог (наличие!), отзывы, сезон → 6–8 идей → пульт `/ideas` |
| Пн | владелец отмечает 3–4 идеи → сценарии RU+DE + шотлист «что снять» |
| Пн–Ср | владелец снимает (≈ 15 мин на 3 ролика), загружает в пульт → рендер → «✅ видео» |
| Вт / Чт / Сб 18:00 | публикации (IG по API, TikTok вручную) |
| Ежедневно | метрики IG + запуски/заказы по меткам |

### Пиллары контента (доли)
| Пиллар | Доля | Пример |
|---|---|---|
| 🐟 Свежий улов / товар крупно | 30 % | «Разламываем воблу — сколько икры?» |
| 🍳 Рецепты и подача | 20 % | «Икра щуки на бутерброд за 30 секунд» |
| 🎬 За кадром | 15 % | упаковка заказа, отбор рыбы |
| 💶 Цена / предложение | 20 % | «Что можно взять на 20 € (минимальный заказ)» — **только цены каталога** |
| ⭐ Отзывы клиентов | 15 % | только реальные отзывы с согласия клиента, без выдуманных |

### Хуки (первые 2 секунды) — шаблоны
«Сколько икры в этой вобле? Проверим» · «Не покупай вяленую рыбу, пока не посмотришь это» · «Это 100 % икра — без головы и костей» ·
«Что взять к пятничному вечеру на 20 €» · «Как отличить хорошую воблу за 3 секунды» · «Распаковка заказа из Telegram-бота».
Хук всегда = **действие с товаром в кадре** (разлом, нарезка, вес на весах), не логотип.

### Частота
MVP: **3 ролика в неделю** × 2 языка (RU-аккаунт и DE-подписи, либо отдельные DE-версии в тех же аккаунтах — решение §11).
Масштаб: 5–7 в неделю. Больше 1 ролика в день на аккаунт — нет смысла и выше риск «спама»
(TikTok ограничивает ≈ 15 постов/сутки через API на автора — наш объём далеко ниже) [ПРОВЕРЕНО: TikTok guidelines, выдержка].

### Обучение на метриках
Каждые 4 недели Content Director пересчитывает для каждого хука/пиллара/формата/языка/товара:
`конверсия = запуски бота с метки / просмотры` и `заказы на 1 000 просмотров`, `€ на ролик`.
Правило: 70 % роликов — по лучшим комбинациям, 30 % — эксперименты. Выводы — в `content-system/learnings.md`
с цифрами; без цифр (меньше 1 000 просмотров или < 5 запусков) — «недостаточно данных», вывод не делается.

### Ограждения (guardrails) — жёстко
1. **Цены** — только из живого каталога бота (data store 203278 / `/catalog`) с датой снимка; если товара нет в наличии — ролик о нём не делается.
2. **Скидки, промокоды, акции** — не придумывать; только то, что владелец утвердил (DIRECTOR.md, правило 1).
3. **Заявления о здоровье** («полезно для сердца», «омега-3 укрепляет…») — запрещены, кроме разрешённых формулировок Health Claims VO
   и только при наличии данных о составе; «натуральный», «без консервантов» — только если подтверждено поставщиком.
4. **Отзывы** — только реальные, с письменным согласием клиента; без выдуманных.
5. **AI-метка** — ставится автоматически, если в ролике AI-голос/аватар/AI-видео (`videos.ai_label_required`).
6. **Публикация — только после «✅ сценарий» и «✅ видео» владельца.** Без исключений, даже по расписанию.
7. Без алкогольных брендов в кадре; «к пиву» — только как название раздела каталога.
8. Тон бренда: просто, честно, по-домашнему; без «кликбейта», который видео не выполняет.

Deepfake (реалистичный человек/голос) — обязательная пометка.
