# Правила проекта (от владельца)

- Отвечать владельцу на русском.
- Любое поручение владельца выполняется через Директора (`raiv-fish-bot/agents/DIRECTOR.md`,
  раздел «Поручения владельца — только через директора»): директор ставит задачу в
  `raiv-fish-bot/agents/tasks/TASKS.md`, назначает агента-исполнителя, исполнитель делает,
  директор проверяет и отчитывается. Так — во всех дальнейших ситуациях.
- Неясные рабочие ситуации решает Директор сам (или нанимает нужного агента) и сообщает решение владельцу;
  владельцу уходят только вопросы из «Неизменных правил» DIRECTOR.md (деньги, цены, удаление данных,
  сценарий 7707233, публикации, сообщения клиентам, шлюзы «без согласования»).
